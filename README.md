# 🗳️ Live Poll App

A real-time polling application that allows users to create polls, vote instantly, and view live results. Built with modern web technologies for a fast and responsive experience.

## 🚀 Features

- 🔐 User Authentication
- ➕ Create New Polls
- 🗳️ Vote in Real-Time
- 📊 Live Poll Results
- 📱 Responsive Design
- 🔄 Real-Time Updates
- 👤 User Dashboard

## 🛠️ Tech Stack

### Frontend
- React.js
- Redux Toolkit
- React Router
- Axios
- CSS / Bootstrap

### Backend
- Django
- Django REST Framework
- SQLite
- JWT Authentication

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/Live_Poll_App.git
```

### Frontend

```bash
cd frontend
npm install
npm start
```

### Backend

```bash
cd backend
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
